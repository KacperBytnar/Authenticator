A "private" password-protected website on user-authentication

This small website contains typescript programs that process passwords. The programs store password hashes in a database. The programs are intended for teaching passwords and cryptographic hashing.

The four main "private" advices for password-based user-authentication are:

  1. Require users to choose passwords of some minimal strength
  2. Only store passwords in hashed form
  3. Use salts (add a salt to a password before hashing)
  4. Hash iteratively to slow down the overall hashing process
These four advices provide a basic level of security; however, for strong authentication you should additionally:
  • Use a hash function that is memory-intensive, in addition to cpu-intensive
  • Use two-factor authentication, that is, add a second factor or channel of authentication, in addition to the user password
